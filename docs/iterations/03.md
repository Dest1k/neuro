# Итерация 3 / 10 — данные Pearl до полного матричного результата

Дата: 2026-11-11. Корневой `README.md` по требованию владельца остаётся **0 байт**.

## Реализовано

Рабочий ограниченный CPU-проход: фиксированный header/seed → сигнал A/Bt →
commitments → noise seeds → noisy A/Bt → полный K=4096 и все 32 milestone XOR.
Подготовка использует настоящие функции pinned CPPminer. Общий интерфейс —
`native/include/neuro/pearl_input.hpp`; детали — `docs/pearl-input.md`.

Взят первый attempt стратегии zero-B: исходные сигналы нулевые, по seed меняется
одна строка A. Поддержаны cert2 и cert3, явный contiguous8x16, header76/seed32,
размеры M/N кратные128 от128 до1024. Неверные параметры отклоняются до upstream
вызовов. Little-endian требование донорского кодирования проверяется явно.

Официальный BLAKE3 1.8.5 закреплён отдельным submodule; portable C библиотека
собирается без Cargo. Независимый Python-генератор использует официальный
Rust-backed binding с закреплёнными версиями и SHA-256 wheels.

Добавлен `neuro_pearl_probe`: готовый потребитель подготовленных матриц для
нашего CUDA-ядра. Перед GPU он сверяет вход и CPU-результат с независимыми
ожиданиями. Режим `--host-only` уже исполнен; GPU-режим только собран.

## Существенные решения и ограничения

Commitments вычисляются по сигналам до шума. Контракт Bt остаётся
транспонированным. Глобальная конфигурация донора явно выставляется до job key;
между нашими вызовами защищена mutex. Объявленная в доноре функция
`pearl_precompute_noise` не используется: в этой версии она возвращает -1.

Подключены реальные noise/hash/cancellation implementations. Неиспользуемый
сетевой код удаляется linker section GC. Для отдельного Case33 differential
сохраняется GCC LTO рецепт; явная проверка Scalar позволила убрать неиспользуемые
SIMD ветки. Заглушки вместо этих зависимостей не добавлялись.

Задания здесь синтетические, но проходят реальные функции подготовки Pearl.
Физический GPU, Windows, jackpot/target, Rust proof и принятые пулом shares ещё
не проверены. Адаптер выполняет одну ограниченную синхронную подготовку;
последовательность попыток, кэш состояния и отмена внутри этого адаптера пока
не реализованы. Проверки отмены относятся к настоящим донорским builders.
