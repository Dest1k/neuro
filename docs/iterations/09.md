## Implemented

  committed checkout. It retains reachable root history, both complete pinned
  source checkouts and their shallow Git boundaries. Embedded Git configuration
  has no active remotes, credentials, hooks or absolute worktree/object paths.
- `_work/handoff/` carries the generated file manifest, its checksum, the full
  source candidate manifest and a standalone arrival verifier. Metadata stays
  outside the established candidate identity. README remains zero bytes;
  archived CI definitions remain disabled and root Actions are refused.
- `tools/handoff_preflight.py` inspects Linux VM prerequisites for basic,
  proof and CUDA-compilation stages. It supports explicit installed tool paths,
  verifies the exact Rust release/commit/host and lockfiles, and never invokes
  rustup proxies to install a missing compiler. Optional fixture checks require
  the supported CPython/binding version and an actual import/hash check.
- `docs/handoff-runbook.md` supplies executable first steps, genuine proof/CPU
  gates, Windows source prepositioning and owner-machine progression. It keeps
  real DSH dispatch accounting and visible SRBMiner restoration explicit.

The package does not contain compilers, downloaded Cargo dependencies, build
outputs, private profiles, budget databases or runtime search/GPU journals.

its separately acquired pinned dependencies.
